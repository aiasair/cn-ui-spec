# 行高与间距场景规范

用于落实汉界的行高与间距规则，已整合用户提供的排版与 UI/UX 汇总规范。以下为默认设计基线，结合字体、宽度、文字长度和设备检查实际表现。Web 数值采用 CSS px，默认根字号 16px；原生 App 按平台逻辑单位与文字缩放机制实现对应关系。

## 解释与优先关系

- 行高是行盒高度；段落间距是相邻段落行盒之间额外增加的空间；元素间距是标题、正文、数值等元素之间的距离。不能把三者相加后当成一个 line-height。
- 字号对应的通用默认行高仅在[字号与文字样式](typography.md)维护；此处只列场景覆盖与元素关系，避免两处维护同一全表。
- 所有说明、描述、副标题、图注都先通过规则二的必要性判断，再应用间距；示例关系不意味着必须创建对应文案。
- 为保持既有规则一的可读性，文档中的错误提示 12/18 不作为关键错误的默认样式：桌面优先采用 14/22，移动端 16/24，并保留 4–6px 关联间距。
- 13/20 紧凑表格与小按钮仅限桌面显式紧凑变体，13px 不用于主要操作或重要阅读，不改变普通 UI 的 14px 基准，不推广到移动操作区。

## 标题与相邻内容

| 元素关系 | 默认间距 |
| --- | --- |
| 页面大标题 → 必要副标题 | 8–12px |
| 页面大标题 → 实质描述正文 | 12–16px |
| 页面标题 → 下方内容区 | 24–32px |
| 模块标题 → 必要说明 | 4–8px |
| 模块标题 → 表格、卡片等业务内容 | 16–24px |
| 卡片标题 → 必要描述 | 4–8px |
| 小标题 → 正文 | 8–12px |

普通标题与必要说明默认可选 8px，模块间默认 32px。关联说明删除后，直接采用标题到业务内容的关系，不叠加已删除说明的间距。

## 正文与段落

| 内容类型 | 字号 / 行高 | 段落额外间距 |
| --- | --- | --- |
| 普通 UI | 14/22px | 8–12px |
| AI 对话 | 16/26px | 12–16px，默认 16px |
| 知识库正文 | 16/26–28px | 16px |
| 阅读文章 | 18/29–32px | 16–24px |
| 确有必要的辅助内容 | 12–13/18–20px | 4–8px |

同段自动换行仅由行高决定；不要用空段落、重复换行或 `<br>` 堆出段距。18/28 是通用大号正文默认，18/29–32 是长文阅读覆盖；16px 长文可按字号规范放宽至 27–29px。业务控件不继承文章的段落 margin。

## 数字与卡片信息组

| 元素关系 | 默认间距 |
| --- | --- |
| 上方标签 → 下方大数字 | 4–8px，默认 4px |
| 大数字 → 同行单位 | 0–4px |
| 大数字 → 实际趋势信息 | 8px |
| 指标组 → 下一指标组 | 16–24px |

32–40px 指标数字可用 1.1–1.25 倍行高，不套用文章行高。卡片内部优先用 4px 关联标签与数值、8px 关联标题与必要内容、16px 分隔不同信息组；不要为了凑齐结构添加描述或趋势。

## 桌面业务组件

| 组件或关系 | 字号 / 文字行高 | 基准高度或间距 |
| --- | --- | --- |
| 普通数据表格 | 14/22px | 行高度 44–48px |
| 显式紧凑数据表格 | 13/20px | 行高度 36–40px |
| 导航菜单 | 14/22px | 条目高度 40px |
| 下拉菜单 | 14/22px | 条目高度 36–40px |
| 普通按钮 | 14/22px | 高度 36–40px |
| 显式小号按钮 | 13/20px | 高度 28–32px |
| 输入框 | 14/22px | 高度 36–40px |
| 表单标签 → 输入框 | 14/22px | 6–8px |
| 表单字段 → 下一字段 | — | 16–24px |
| 输入框与错误提示 | 关键提示 14/22px | 4–6px |
| 弹窗标题 → 必要描述 | 标题 20/28px | 8–12px |
| 弹窗正文 → 操作按钮 | 正文 14/22px | 24px |

这些高度是默认单行状态的基准，不是多行或放大后的固定上限。表格使用文字行高与单元格内边距构成整行，随多行内容自然增高；菜单、按钮与输入区域同样不能裁切放大后的文字。

## AI 对话与 Markdown 阅读区

默认 16/26px 正文，不把连续几段回答拆成独立卡片。

| 内容关系 | 默认间距 |
| --- | --- |
| 同段自动换行 | 由 26px 文字行高决定 |
| 两个自然段 | 16px |
| H1 → 正文 | 16px |
| H2 → 正文 | 12px |
| H3 → 正文 | 8px |
| 正文 → 下个章节标题 | 24–32px |
| 列表条目 → 下一条目 | 4–8px |
| 列表 → 后续正文 | 16px |
| 正文 → 代码块 | 12–16px |
| 代码块 → 后续正文 | 16px |
| 图片 → 必要图注 | 8px |
| 引用块 → 正文 | 16px |

这一场景表优先于普通组件的标题间距表。标题前间距通常大于标题后间距；明确相邻内容的间距归属，避免段落 margin、标题 margin 和父级 gap 重复累计。可统一控制单侧 margin、使用选择器按相邻关系覆盖，或为特定组使用 gap；验收实际间距，不依赖 margin 折叠的偶然结果。

## 移动端与特殊阅读场景

| 场景 | 默认字号 / 行高或间距 |
| --- | --- |
| 手机正文 | 16/26px |
| 手机阅读型长文 | 16–18px / 27–31px |
| 手机页面标题 | 24/32px |
| 手机菜单、操作、表单输入文字 | 16/24px |
| 手机卡片标题 → 必要说明 | 8px |
| 手机段落间距 | 12–16px |
| 手机内容模块间距 | 24–32px |
| 明确提供的老年友好阅读模式 | 正文可用 18–20px，行高约 1.6–1.8 |

移动端 16/24px 是操作与输入场景覆盖，不改变阅读正文的 16/26px 默认。不从桌面组件表直接套用 13px 小按钮或固定高度；宽度不足时允许换行和增高。

## Token 与实现约束

字号、行高、字重、间距都映射至项目统一的语义 Token；以下命名仅作实现示例，不要求替换已有体系。无单位行高适用于可能改变字号的文字样式；具体字号样式可用配对的 px/rem 行高 Token，不能在混合多种字号的父容器上固定统一的绝对行高。

```css
:root {
  font-size: 100%;
  --han-font-ui: 0.875rem;
  --han-font-reading: 1rem;
  --han-leading-ui: 1.5714285714; /* 默认 14/22 */
  --han-leading-reading: 1.625;   /* 默认 16/26 */
  --han-space-1: 0.25rem;
  --han-space-2: 0.5rem;
  --han-space-3: 0.75rem;
  --han-space-4: 1rem;
  --han-space-6: 1.5rem;
  --han-space-8: 2rem;
  --han-space-12: 3rem;
  --han-gap-title-description: var(--han-space-2);
  --han-gap-paragraph: var(--han-space-4);
  --han-gap-heading-content: var(--han-space-3);
  --han-gap-section: var(--han-space-8);
  --han-gap-label-value: var(--han-space-1);
}
```

只有实际渲染了必要内容才使用对应语义间距。不要复制文档示例中带说明的卡片结构作为全站必备结构，也不要用全局 `height: auto` 覆盖所有控件；针对内容容器和文字缩放修正实际裁切问题。

## 文字间距覆盖验收

按 [W3C WCAG 2.2 SC 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)，对支持这些样式的 Web 内容，在只覆盖以下适用属性时，不得丢失内容或功能：

- 文字行高至少为字号的 1.5 倍。
- 段后间距至少为字号的 2 倍。
- 字符间距至少为字号的 0.12 倍。
- 词间距至少为字号的 0.16 倍。

这些是用户覆盖测试值，不是默认视觉样式，也不要求产品提供一组间距设置控件。对某种语言和文字系统不适用的属性按其适用性处理；中文与拉丁文字混排需覆盖相应适用属性。展示标题即使默认 32/40px，也必须在用户增加间距后保留内容与操作。

用实际页面检查长标题、多行表格单元格、菜单、按钮、错误提示、阅读段落与代码块，确认容器可增长，没有裁切、覆盖、重叠或操作失效。分别记录默认间距、窄屏、文字放大与间距覆盖的验证情况；未运行的项目标为未验证，不把静态 Token 检查当成完整验收。
