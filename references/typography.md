# 字号与文字样式

## 字号核心约束

1. 中文文字不得小于 **12px**。12px 仅用于低优先级辅助信息，不能承载主要内容、主要按钮、表单或关键操作；不得通过缩放变相显示更小文字。
2. 桌面端业务 UI 基准 **14px**；文章、知识库、AI 对话回答等连续阅读内容基准 **16px**。AI 工作台可同时使用 14px 操作区和 16px 阅读区。13px 用于次要文字或明确的桌面紧凑场景，不用于重要阅读或主要操作。
3. 移动端业务 UI 与正文默认 **16px**，长文可用 18px；辅助信息及表格按下表处理。不得整体缩小桌面页面实现移动适配。
4. 常规字号阶梯为 **12、13、14、16、18、20、24、28px**；下表移动端 H2 的 **22px** 是已明确允许的角色例外。阶梯是可选集合，单个业务界面通常选 3–5 种主要字号，不要求用齐全部档位。
5. 标题结合字号、字重和间距建立层级。特殊展示型标题可突破常规阶梯，但应在设计 Token 中统一定义并说明用途，不能把例外扩散到普通业务文字。

下表数值为 Web 的 CSS px 设计基准，按浏览器默认 16px 根字号计算；用户文字缩放后的实际尺寸不受此上限限制。原生 App 使用平台的逻辑字号单位与可缩放文字样式表达对应层级，不能将 CSS px 当成设备物理像素直接套用，也不能锁死系统文字缩放。

## 配套默认行高与字重

| 字号 | 默认行高 | 主要用途 |
| --- | --- | --- |
| 12px | 18px | 辅助信息 |
| 13px | 20px | 次要文字 |
| 14px | 22px | UI 正文 |
| 16px | 26px | 内容阅读 |
| 18px | 28px | 大号正文 |
| 20px | 28px | 小标题 |
| 24px | 32px | 模块标题 |
| 28px | 36px | 页面标题 |
| 32px | 40px | 大型标题 |
| 36px | 44px | 展示标题 |
| 40px | 48px | 首页主视觉 |
| 48px | 56px | 超大标题 |
| 56px | 64px | 品牌展示 |

- 上表是默认文字样式，不是固定容器高度；有明确阅读场景时可按[行高与间距场景规范](spacing.md)调整，较长的 16px 中文文章可用 27–29px。移动端 22px 模块标题默认 30px 行高（约 1.36 倍），并检查实际字体是否拥挤或裁切。32–56px 属于展示角色，不扩充普通业务 UI 的常规字号阶梯。
- 字重优先保留 400（正文）、500（强调）、600（标题），避免大量使用 300 或更细字重。
- 不用增加十几种字号来区分层级；优先在已有档位中配合字重和间距。

## 统一实现

- 字号、行高、字重通过 Typography Design Tokens 或组件库主题统一控制，业务组件只引用语义角色或 Token，不自行硬编码配置。已有体系可映射角色，无须改用指定命名。
- Web 优先使用 `rem`，根字号采用 `100%` 并尊重用户设置。默认根字号 16px 时，12/13/14/16/18/20/22/24/28px 分别对应 0.75/0.8125/0.875/1/1.125/1.25/1.375/1.5/1.75rem。
- Web 行高优先用无单位比例，使文字放大时同步增长；上表给出默认尺寸下的视觉目标。不要用固定高度裁切多行文字。
- 按桌面与移动端映射语义角色，而不是全局比例缩放；移动输入框默认 16px，不为压缩空间降为小字号。
- 中文字体栈可采用系统字体与中文回退：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`；已有合适字体可保留。

## 阅读可用性与验收

文字颜色建议为主要文字 `#1F2329`、次要文字 `#595959`、弱化文字 `#767676`，它们是可选参考值，不能假定在所有背景上都合格。按实际主题与背景检查对比度：普通文本至少 4.5:1；符合 WCAG 大号文本定义时至少 3:1，不可把 16px 正文视为大号文本。

Web 应支持文字放大至 200% 而不丢失内容或功能；原生 App 检查系统文字放大后的阅读与操作。不能只凭源码数值宣称可读性已通过。

在任务已有的预览或运行环境中，重点检查：

- 桌面 UI 与阅读内容是否分别采用 14px、16px 基准；移动端正文和操作文字是否为 16px。
- 是否存在低于下限、通过缩放变小、或把关键内容放入 12px 的情况。
- 组件主题与业务样式是否仍存在偏离规范的字号覆盖。
- 中文换行、标题层级、行高和文字放大后，是否出现裁切、遮挡或操作失效。

报告实际检查结果；无法运行预览、测量对比度或验证文字缩放时，明确标为未验证。只修复本次授权范围的问题，发现的新规则仍按前述同意流程处理。

可读性条款依据：[W3C WCAG 2.2 文字对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[文字缩放说明](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)。本技能的 12/14/16px 产品字号约定来自用户，不应归因于 WCAG 或声称符合这些字号即可满足全部无障碍要求。
