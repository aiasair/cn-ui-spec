# 中文本地化、响应式与无障碍

## 中文表达与格式

- 项目术语保持一致，维护有实际歧义的术语对照，如账号／账户、保存／提交／发布、禁用／停用；先区分业务含义，不机械替换为同一词。
- 中文正文采用适当全角标点；英文、代码、路径、网址及代码标识保留其语法。中英文、数字与单位的间隔按项目统一约定，不逐页面临时发挥。
- 按钮优先表达动作与对象；反馈表达事实和必要下一步，全部文案服从[精简说明规则](interface-copy.md)。
- 日期统一格式与时区语义，例如绝对日期 `YYYY-MM-DD`；相对时间提供获取完整时间的途径。不能用执行机器的时区替代用户或业务时区。
- 金额、货币、文件大小、流量、Token、百分比统一数值精度与单位。需要区分时明确十进制与二进制单位，不能混淆次数、Token、金额或额度。
- 对长中文词、长英文、网址、路径及窄屏截断进行实际验证；保留必要内容的完整访问途径。

## 响应式

- 移动正文、操作与输入默认 16px，具体行高与间距见[场景表](spacing.md)。文字自然换行、容器随内容增高；禁止整体缩小页面冒充适配。
- 内容布局按可用宽度、信息优先级与操作方式调整，不能只改字号或挤压间距。图标视觉尺寸与可点击范围分开考虑，移动端采用清楚且宽裕的触控目标。
- 桌面、平板、手机及放大后的状态应保留关键信息、控件和操作；大弹窗、表格、工具栏、代码与长路径有实际可用的溢出策略。
- 原生 App 使用平台文字缩放与逻辑单位，不直接套用物理像素；已有的系统可访问性行为不因自绘组件而失效。

## 无障碍

- P1：普通文本与实际背景对比度至少 4.5:1，符合大号文本定义时至少 3:1；16px 正文不能视为大号文本。不同主题和交互状态分别检查，不能只测一张白底静态截图。
- P0/P1：关键流程可用键盘完成，焦点可见且顺序合理；交互有正确语义、名称、状态与关联，不用可点击的普通文本冒充完整控件而丢失键盘能力。
- 仅有图标的操作提供可访问名称；内容图片提供适当替代文字，纯装饰内容不制造重复读屏噪声。精简可见说明不意味着删除读屏所需名称。
- 支持 Web 文字放大至 200% 后不丢内容与功能；系统文字缩放及窄屏下不得遮挡主要操作。对话框焦点与关闭行为见[交互规则](interaction.md)。
- 支持用户覆盖文字行高、段距、字符与词间距后的可用性；具体覆盖值与语言适用范围只在[间距验收](spacing.md#文字间距覆盖验收)维护，不复制成默认样式。
- 尊重减少动态效果的偏好；必要状态与结果仍应清晰可知。

## 验证边界

对比度、键盘、语义名称、文字缩放、文字间距覆盖和窄屏属于不同检查项；某一项通过不能代替其余项目。可用现有浏览器测试或可访问性扫描辅助，但动态背景、复杂弹层和实际读屏体验仍可能需要人工核验。报告实际覆盖与未验证项，不因遵守字号表就宣称全面符合无障碍标准。

规范依据：[文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)、[文字缩放](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)、[文字间距](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)。其余布局及中文格式为汉界产品约定。
